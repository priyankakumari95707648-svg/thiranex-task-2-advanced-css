# Thiranex Task 2 — Advanced CSS3 & Responsive Architecture

A responsive personal portfolio built for the Thiranex Web Development Internship.

## Requirements covered

- CSS Grid for two-dimensional page layouts
- Flexbox for component alignment
- Mobile-first responsive media queries
- CSS custom properties for a dynamic light/dark theme
- Responsive layouts for mobile, tablet and desktop
- Accessible navigation and form controls
- Semantic HTML5 structure inherited from Task 1
- Interactive mobile navigation
- Persistent theme preference using localStorage
- Reduced-motion support
- Responsive project cards and typography

## Project structure

```text
thiranex-task-2/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## How to run

Open `index.html` in a browser.

For the best experience, use VS Code with Live Server or any local static server.

## GitHub

Upload all files and folders while keeping the folder structure intact. Do not upload only the ZIP contents as loose files without the `css` and `js` folders.
